OmaApple v1 wireframe

Low-fidelity layout for the native Quickshell UI. Boxes are structure, not final chrome. Product UI lives in the Omarchy bar and a panel — not inside Apple’s website. Playback is a hidden Chromium MusicKit engine the user never browses.

Keyboard (v1): Ctrl+F search · Tab cycle regions · Space play/pause · Ctrl+←/→ prev/next · Shift+←/→ seek · Ctrl+↑/↓ volume · Ctrl+S / Ctrl+R shuffle / repeat · Esc close. Queue is a sidebar page, same chrome as Listen Now.
